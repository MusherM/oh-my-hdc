已完成本机首轮验收。Rust CLI、单用户后台调度器、项目级 Codex skill/hook、双语说明与四目标 CI 已实现。18 项自动化测试通过，macOS ARM64 release 包已构建并解包运行；真实手机只读申请—执行—释放通过。这不代表全部平台或完整应用业务验收完成。

实际实现

  • 设备独占、可满足请求 FIFO、指定或任意设备申请、独立凭证、普通会话空闲 10 分钟回收。
  • 后台日志不续期；托管长测试由脚本完成信号与显式超时控制，不依赖 agent 心跳，结束后自动清理与释放。
  • 进程监督、调度器断开时取消进程树、崩溃恢复隔离、旧凭证拒绝、清理失败阻止交接。
  • 清理声明应用与会话转发；hdc 服务维护先排空会话，并发请求合并，失败暂停分配。
  • Codex 项目配置合并与备份；常见直接 hdc 调用拦截；doctor 不把配置存在当作运行时保护。

本轮发现并修复

  • 真实设备对未安装应用返回 10104002。仅在同时明确说明应用未安装时接受“无需停止”，其他错误仍隔离设备。首次失败记录为当时结果：/tmp/omh-device-smoke-sk22_lv9。
  • 命令结果先于周期调度处理，可能误拒绝紧接着的命令；现在在接收新操作前同步处理完成结果，并增加连续命令回归测试。
  • 旧任务取消不得影响设备的新占用者；并行清理不能把另一台设备的活动清理操作当成崩溃遗留。
  • 端口转发按完整规则删除；已有转发不接管，删除后再次确认不存在。

运行边界

  • 同一 OS 用户、同一状态目录共享调度；不同状态目录的池、IDE、人工终端和未接入项目不受协调。
  • hook 是防误用机制，不是安全沙箱。不解释任意脚本，也不能防同权限 agent 刻意绕过。Codex 官方 hook 边界。
  • 普通执行支持管道输入输出，不支持裸交互终端；托管脚本必须自行确认业务成功，不得主动脱离进程组。
  • 监督进程异常且无法确认进程树停止时保持隔离。Unix 可在确认持久化进程组已不存在后恢复；缺少可信进程标识等情况不强制清除状态。
  • 状态目录含凭证与测试输出，需保持私有；证据与历史不自动删除。测试专用临时调度器已停止。
